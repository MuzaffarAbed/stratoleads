# Google Apps Script Integration

This folder is where Cursor should create the Apps Script source file(s), deployment guide, and test payloads.

## Setup outline
1. Create a Google Sheet in the STRATO-managed Google Workspace.
2. Add `Leads` and `BusinessCards` tabs with the headers in `../04_GOOGLE_SHEETS_AND_EMAIL.md`.
3. Open Extensions → Apps Script.
4. Add the implementation generated by Cursor from the integration specification.
5. Set Script Properties for the shared secret and approved notification recipients.
6. Deploy as a Web App under the approved STRATO account, using the least-permissive access model compatible with server-to-server requests.
7. Set `GOOGLE_APPS_SCRIPT_URL` and `GOOGLE_APPS_SCRIPT_SHARED_SECRET` in the Next.js server environment.
8. Test from the Next.js API, not from a browser that exposes secrets.

Do not commit production secrets or real lead data.
